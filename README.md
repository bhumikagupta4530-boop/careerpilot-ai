# 🚀 CareerPilot AI

CareerPilot AI is a web-based career guidance tool that helps students generate a structured roadmap for Engineering careers based on their current level, interests, and study capacity.

Currently, the system focuses only on **Engineering field roadmaps**, but it is designed to expand to other career domains in the future.
--

## 🎯 How It Works

The system takes user input step-by-step:

1. Select Engineering branch preference  
2. Choose skill level (Beginner / Intermediate / Advanced)  
3. Enter daily study hours  

Based on these inputs, it generates a **personalized engineering roadmap**.

---

## ⚙️ Current Features

- Step-by-step input form
- Engineering branch-based roadmap generation
- Beginner to advanced level mapping
- Study hours-based planning
- Simple and interactive UI
